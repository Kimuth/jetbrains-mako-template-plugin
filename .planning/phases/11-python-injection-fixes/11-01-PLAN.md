<objective>
TDD fix for INJECT-01: make updateText() in all three injection host mixins throw
UnsupportedOperationException instead of silently returning `this`.

Purpose: The current silent no-op misleads callers into thinking the round-trip edit
succeeded. UnsupportedOperationException gives a clear failure signal — same design
decision as setName() in Phase 10.

Output: MakoInjectionHostTest.kt with 3 failing tests, then 3 fixed mixin files, then all tests green.
</objective>
