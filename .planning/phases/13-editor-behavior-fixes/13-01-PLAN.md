<objective>
Fix three independent editor behavior defects: wrong default color for code block content tokens,
missing brace pair entry for module blocks, and silent overflow in lexer brace-depth encoding.

Purpose: Code content inside `<% %>` and `<%! %>` blocks currently inherits the STRING (string
literal) color, making it look like a string in editors that use the default scheme. Module blocks
`<%! %>` have no bracket highlighting because MODULE_OPEN was never registered in the brace
matcher. Deep brace nesting silently clamps without any observable signal, making debugging
incremental re-lex issues impossible.

Output: Three single-file patches — one to MakoSyntaxHighlighter.kt, one to MakoPairedBraceMatcher.kt,
one to MakoLexerAdapter.kt — and a passing `./gradlew check`.
</objective>

Current:
```kotlin
override fun getState(): Int {
    val jflexState = super.getState()
```

New:
```kotlin
override fun getState(): Int {
    val jflexState = super.getState()
    val rawDepth = makoFlex.braceDepth
    if (rawDepth > 0xF) {
        LOG.warn("MakoLexerAdapter: braceDepth=$rawDepth exceeds max (15); clamping to 0xF")
    }
    val depth = rawDepth.coerceIn(0, 0xF)
    return jflexState or (depth shl 4)
}
```
