    MakoFileViewProvider wiring HTML PSI tree into every .mako file. Six HINJ requirements (HTML coloring, completion, Emmet, error detection, CSS/JS injection) should all be active in TEMPLATE_TEXT regions.
  </what-built>
  <how-to-verify>
With the fixture .mako file open in the running IDE, check each item:

1. **HTML syntax coloring (HINJ-01):** HTML tags (`<div>`, `<h1>`, `<html>`, etc.) should appear in a different color than the Mako constructs (`<%def`, `${...}`, `%for`). The TEMPLATE_TEXT region should not be plain white/uncolored text.

2. **HTML tag completion (HINJ-02):** Place the cursor inside the `<body>` section and type `<di`. An autocomplete popup should appear suggesting `<div>` and other `<d*` HTML tags.

3. **HTML attribute completion (HINJ-02):** Inside a `<div ` tag, type `cl`. An autocomplete popup should appear suggesting `class=`.

4. **Emmet expansion (HINJ-03):** On a blank line inside `<body>`, type `ul>li*3` then press Tab. The abbreviation should expand to the full HTML list structure.

5. **Python injection still works (regression check):** Click inside `${title}`. Python syntax highlighting should be visible. Add `${undefined_var}` on a new line — it should show a Python "Unresolved reference" warning.

6. **Code folding works (regression check):** A folding gutter icon should appear next to the `<%def name="card(title, body)">` line. Clicking it should collapse the def block.

7. **Structure View works (regression check):** Open View > Tool Windows > Structure (or Alt+7). The structure view should show the `card` def node.

8. **CSS completion (HINJ-05):** Click inside the `<style>` block, position after `body { `, and type `font-`. An autocomplete popup should suggest CSS properties like `font-size`, `font-family`.

9. **JavaScript completion (HINJ-06):** Click inside the `<script>` block, position after `document.`, and confirm member completion suggestions appear.

If any item fails, describe what you see instead of the expected behavior. Type "approved" if all items pass, or describe the failures.
