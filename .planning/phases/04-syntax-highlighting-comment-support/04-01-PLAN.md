  <name>Task 1: Create MakoSyntaxHighlighter, MakoSyntaxHighlighterFactory, and MakoColorSettingsPage</name>
  <files>
    src/main/kotlin/com/github/kimuth/jetbrainsmakotemplateplugin/lang/highlighting/MakoSyntaxHighlighter.kt

  </files>
  <action>
    Create the `lang/highlighting/` package with three files:

    **MakoSyntaxHighlighter.kt** — extends `SyntaxHighlighterBase`:
    - Define `TextAttributesKey` constants in a companion object, ALL prefixed with `MAKO_` to avoid global name collisions:
      - `MAKO_DIRECTIVE` backed by `DefaultLanguageHighlighterColors.KEYWORD` — for TAG_OPEN_DEF, TAG_OPEN_BLOCK, TAG_OPEN_INHERIT, TAG_OPEN_INCLUDE, TAG_OPEN_NAMESPACE, TAG_OPEN_PAGE, END_TAG, CODE_OPEN, MODULE_OPEN
      - `MAKO_EXPRESSION` backed by `DefaultLanguageHighlighterColors.TEMPLATE_LANGUAGE_COLOR` — for EXPR_START, EXPR_END, EXPR_CONTENT, FILTER_SEP, FILTER_NAME
      - `MAKO_CONTROL_LINE` backed by `DefaultLanguageHighlighterColors.KEYWORD` — for CONTROL_LINE
      - `MAKO_LINE_COMMENT` backed by `DefaultLanguageHighlighterColors.LINE_COMMENT` — for LINE_COMMENT
      - `MAKO_BLOCK_COMMENT` backed by `DefaultLanguageHighlighterColors.BLOCK_COMMENT` — for DOC_OPEN, DOC_CONTENT, DOC_CLOSE
      - `MAKO_TAG_ATTR_NAME` backed by `DefaultLanguageHighlighterColors.INSTANCE_FIELD` — for TAG_ATTR_NAME
      - `MAKO_TAG_ATTR_VALUE` backed by `DefaultLanguageHighlighterColors.STRING` — for TAG_ATTR_VALUE
      - `MAKO_TAG_CLOSE` backed by `DefaultLanguageHighlighterColors.BRACKETS` — for TAG_CLOSE, CODE_CLOSE
      - `MAKO_CODE_CONTENT` backed by `DefaultLanguageHighlighterColors.STRING` — for CODE_CONTENT, MODULE_CONTENT
    - Pre-allocate `Array<TextAttributesKey>` constants (DIRECTIVE_KEYS, EXPRESSION_KEYS, etc.) to avoid per-call allocation.
    - `getHighlightingLexer()` returns a fresh `MakoLexerAdapter()` (new instance, never cached).
    - `getTokenHighlights(tokenType)` uses a `when` expression mapping each MakoTokenTypes constant to its key array. Return `EMPTY_KEYS` for TEMPLATE_TEXT and all unrecognized tokens (the HTML layer handles those). Include TAG_ATTR_EQ in EMPTY_KEYS (platform punctuation, no special color needed).

    **MakoSyntaxHighlighterFactory.kt** — extends `SyntaxHighlighterFactory()`:
    - `getSyntaxHighlighter(project, virtualFile)` returns `MakoSyntaxHighlighter()`.

    **MakoColorSettingsPage.kt** — implements `ColorSettingsPage`:
    - Companion object with `DESCRIPTORS` array of `AttributesDescriptor` entries, one per TextAttributesKey defined in MakoSyntaxHighlighter. Use user-friendly display names:
      - "Directive (<%def>, <%block>, ...)" for MAKO_DIRECTIVE
      - "Expression (${...})" for MAKO_EXPRESSION
      - "Control line (% for, % if, ...)" for MAKO_CONTROL_LINE
      - "Line comment (## ...)" for MAKO_LINE_COMMENT
      - "Block comment (<%doc>)" for MAKO_BLOCK_COMMENT
      - "Tag attribute name" for MAKO_TAG_ATTR_NAME
      - "Tag attribute value" for MAKO_TAG_ATTR_VALUE
      - "Tag close (%>, </%...>)" for MAKO_TAG_CLOSE
      - "Code block content" for MAKO_CODE_CONTENT
    - `getIcon()` returns `MakoIcons.FILE`
    - `getHighlighter()` returns `MakoSyntaxHighlighter()`
    - `getDisplayName()` returns `"Mako"` (the category label in Settings tree)
    - `getDemoText()` returns a representative Mako snippet with directives, expressions, control lines, comments, and code blocks. Use `${'$'}` Kotlin escaping for `$` inside the raw string.
    - `getAttributeDescriptors()` returns the DESCRIPTORS array
    - `getColorDescriptors()` returns `ColorDescriptor.EMPTY_ARRAY`
    - `getAdditionalHighlightingTagToDescriptorMap()` returns `null`
  </action>

      - `BracePair(MakoTokenTypes.TAG_OPEN_DEF, MakoTokenTypes.END_TAG, false)`
      - `BracePair(MakoTokenTypes.TAG_OPEN_BLOCK, MakoTokenTypes.END_TAG, false)`
      - `BracePair(MakoTokenTypes.DOC_OPEN, MakoTokenTypes.DOC_CLOSE, false)`
      - `BracePair(MakoTokenTypes.EXPR_START, MakoTokenTypes.EXPR_END, false)`
      - `BracePair(MakoTokenTypes.CODE_OPEN, MakoTokenTypes.CODE_CLOSE, false)`
    - `getPairs()` returns the pairs array
    - `isPairedBracesAllowedBeforeType(lbraceType, contextType)` returns `true`
    - `getCodeConstructStart(file, openingBraceOffset)` returns `openingBraceOffset`

    - `getBlockCommentPrefix()` returns `"<%doc>"`
    - `getBlockCommentSuffix()` returns `"</%doc>"`
    - `getCommentedBlockCommentPrefix()` returns `null`
    - `getCommentedBlockCommentSuffix()` returns `null`
