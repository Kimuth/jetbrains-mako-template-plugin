Create a new package directory `lang/completion/` and file `MakoCompletionContributor.kt`.

Package: `com.github.kimuth.jetbrainsmakotemplateplugin.lang.completion`

**Class structure:** One `MakoCompletionContributor : CompletionContributor()` class with two private inner provider classes. The `init` block calls `extend()` twice.

**First extend — COMP-01 tag-name completion:**
```kotlin
extend(
    CompletionType.BASIC,
    PlatformPatterns.psiElement(),   // broad pattern; narrowed inside provider
    TagNameCompletionProvider()
)
```

**TagNameCompletionProvider logic:**
1. Get `parameters.originalFile` — if its language ID is not `"Mako Template"`, return immediately.
2. Get `parameters.offset`. If `offset < 2`, return.
3. Read `parameters.originalFile.text.substring(offset - 2, offset)`. If it is not `"<%"`, return.
4. Offer 7 `LookupElementBuilder` items. The lookup string for each is the full tag name (e.g., `"<%def"`). Use `withPresentableText(tagName)` and `withBoldness(true)`.
5. Use `result.withPrefixMatcher("")` (empty prefix matcher) so the platform does not filter out the `<%` prefix from items.
6. Insert handler for all tags except `<%doc`: call `insertCtx.document.replaceString(insertCtx.startOffset - 2, insertCtx.tailOffset, tagName + " ")` to overwrite the typed `<%` (and any partial letters already typed) with the full tag name plus a trailing space that positions caret for attribute entry. Commit the document inside the handler.
7. Insert handler for `<%doc` specifically: replace with `"<%doc>\n</%doc>"` and position caret on the inner blank line using `insertCtx.editor.caretModel.moveToOffset(...)`.

**Tag name list** (constant at file level):
```kotlin
private val TAG_NAMES = listOf("<%def", "<%block", "<%inherit", "<%include", "<%namespace", "<%page", "<%doc")
```

**Second extend — COMP-02 attribute completion on TAG_ATTR_NAME leaf:**
```kotlin
extend(
    CompletionType.BASIC,
    PlatformPatterns.psiElement(MakoTokenTypes.TAG_ATTR_NAME),
    TagAttrCompletionProvider()
)
```

**Also add a second extend for caret on whitespace inside a tag (caret before first attribute has been typed):**
```kotlin
extend(
    CompletionType.BASIC,
    PlatformPatterns.psiElement(TokenType.WHITE_SPACE),
    TagAttrCompletionProvider()
)
```

**TagAttrCompletionProvider logic:**
1. Walk `parameters.position.parent` upward until a recognized tag type is found or `PsiFile` is reached.
2. Tag attribute map (defined as a private file-level val):
   ```kotlin
   private val TAG_ATTRIBUTES: Map<Class<out PsiElement>, List<String>> = mapOf(
       MakoDefTag::class.java      to listOf("name", "buffered", "cached", "cache_key",
                                              "cache_timeout", "cache_type", "cache_url",
                                              "cache_dir", "cache_region", "filter", "decorator"),
       MakoBlockTag::class.java    to listOf("name", "filter", "cached", "cache_key",
                                             "cache_timeout", "cache_type", "cache_url",
                                             "cache_dir", "cache_region"),
       MakoInheritTag::class.java  to listOf("file"),
       MakoIncludeTag::class.java  to listOf("file", "args"),
       MakoNamespaceTag::class.java to listOf("name", "file", "import", "module"),
       MakoPageTag::class.java     to listOf("args", "expression_filter", "cached", "cache_key",
                                              "cache_timeout", "cache_type", "cache_url",
                                              "cache_dir", "cache_region")
   )
   ```
3. When a matching tag class is found, add one `LookupElementBuilder` per attribute:
   - Lookup string: the attribute name (e.g., `"name"`)
   - Tail text: `"=\"\""` (shown grayed, `true` for italic)
   - Insert handler: insert `=""` at `ctx.tailOffset`, then move caret to `ctx.tailOffset - 1` (between the quotes). Call `ctx.commitDocument()`.
4. After adding all items, return immediately.

**Imports needed:**
- `com.intellij.codeInsight.completion.*`
- `com.intellij.codeInsight.lookup.LookupElementBuilder`
- `com.intellij.patterns.PlatformPatterns`
- `com.intellij.psi.PsiElement`, `PsiFile`, `TokenType`
- `com.intellij.psi.util.PsiTreeUtil` (if needed)
- `com.github.kimuth.jetbrainsmakotemplateplugin.lang.MakoTokenTypes`
- `com.github.kimuth.jetbrainsmakotemplateplugin.lang.psi.*` (MakoDefTag, MakoBlockTag, MakoInheritTag, MakoIncludeTag, MakoNamespaceTag, MakoPageTag)

**Anti-patterns to avoid:**
- Do NOT match on `TAG_OPEN_DEF` or similar tag-open tokens for tag-name completion — the dummy identifier breaks the lexer before those tokens appear. Always use raw text inspection.
- Do NOT omit the `language = "Mako Template"` guard — it is enforced in plugin.xml, but the inner guard in `TagNameCompletionProvider` (language ID check) provides defense-in-depth.
- Do NOT cache `Language.findLanguageByID(...)` calls in the contributor class.
