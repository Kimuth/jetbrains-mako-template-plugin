    - Expected: ERROR annotation with descr="Unclosed <%block>: missing closing tag" on the <%block token range

    Case 3: well-formed def tag → no error annotation

    Test method approach — use test data files (not inline configureByText) to keep test data readable:

    Test data file format for WellFormedDefTag.mako (no error markers):
    ```
    <%def name="foo">
    content
    </%def>
    ```
