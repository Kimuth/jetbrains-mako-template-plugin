<objective>
Implement CSS sub-language injection into `<style>` elements in `.mako` files by registering a `MakoCssInjector` (MultiHostInjector) that targets XmlText nodes within HTML PSI tree `<style>` tags. Register it in plugin.xml. Add structural automated tests. Verify the full test suite still passes.

Purpose: Closes HINJ-05. The `MakoFileViewProvider` (Phase 18) already creates a valid HTML PSI tree for every `.mako` file. The platform's CSS injection does not fire automatically in PyCharm Community because no built-in `<style>` injector is registered there. `MakoCssInjector` fills that gap. JavaScript injection (HINJ-06) is handled by the platform's `HtmlScriptLanguageInjector` which already fires on our HTML PSI tree when the JavaScript plugin is present — no additional code is needed for HINJ-06.

Output: `MakoCssInjector.kt`, updated `plugin.xml`, `MakoCssInjectorTest.kt`, passing `./gradlew check`.
</objective>

    Create `src/main/kotlin/com/schtilig/mako/lang/injection/MakoCssInjector.kt`:

    Package: `com.schtilig.mako.lang.injection`

    Implement `MakoCssInjector : MultiHostInjector` with exactly these two overrides:

    **`elementsToInjectIn()`:** Returns `listOf(XmlText::class.java)` — targets XmlText leaf nodes (the injection host; XmlTextImpl implements PsiLanguageInjectionHost, confirmed via javap).

    **`getLanguagesToInject(registrar, context)`:** In this order:
    1. `val css = Language.findLanguageByID("CSS") ?: return` — null guard for CSS plugin absence (CRITICAL: do NOT use `CssLanguage.INSTANCE` — causes ClassNotFoundException if CSS plugin not installed)
    2. `if (!context.isValid) return` — guard against stale PSI
    3. `val xmlText = context as? XmlText ?: return`
    4. `if (!HtmlUtil.isHtmlTagContainingFile(xmlText)) return` — restricts to HTML files only; prevents injection into XML config files or other non-HTML XML that happen to have a `<style>` element name
    5. `val parentTag = xmlText.parentTag ?: return`
    6. `if (parentTag.localName.lowercase() != "style") return` — use localName string comparison (NOT HtmlUtil.isStyleTag — that method was not confirmed via javap; STYLE_TAG_NAME constant exists but isStyleTag method may not; string comparison is the safe fallback per research open questions)
    7. `val text = xmlText.text ?: return`
    8. `if (text.isEmpty()) return`
    9. `registrar.startInjecting(css).addPlace(null, null, xmlText as PsiLanguageInjectionHost, TextRange(0, text.length)).doneInjecting()`

    Required imports:
    - `com.intellij.lang.Language`
    - `com.intellij.lang.injection.MultiHostInjector`
    - `com.intellij.lang.injection.MultiHostRegistrar`
    - `com.intellij.openapi.util.TextRange`
    - `com.intellij.psi.PsiElement`
    - `com.intellij.psi.PsiLanguageInjectionHost`
    - `com.intellij.psi.xml.XmlText`
    - `com.intellij.xml.util.HtmlUtil`

    KDoc comment explaining: injects CSS into `<style>` elements in HTML PSI tree created by MakoFileViewProvider (Phase 18); no-ops when CSS plugin absent; JavaScript handled by platform's HtmlScriptLanguageInjector; registered via `<multiHostInjector>` in plugin.xml (HINJ-05).

    Do NOT: write a MakoJsInjector — the platform's HtmlScriptLanguageInjector already handles `<script>` tags; adding a second injector causes double-injection and duplicate completions.
