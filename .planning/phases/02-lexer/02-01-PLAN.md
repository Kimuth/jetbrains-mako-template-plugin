**Step 1: Create `src/main/grammars/` directory and `MakoLexer.flex`.**

The JFlex file must have this exact structure:

**Header section:**
```
package com.github.kimuth.jetbrainsmakotemplateplugin.lang;

import com.intellij.lexer.FlexLexer;
import com.intellij.psi.tree.IElementType;
import static com.github.kimuth.jetbrainsmakotemplateplugin.lang.MakoTokenTypes.*;
import com.intellij.psi.TokenType;
```

**Options section (`%%`):**
```
%class _MakoLexer
%implements FlexLexer
%unicode
%function advance
%type IElementType
%eof{  return;
%eof}
```

**User code section (`%{ ... %}`):**
- Default constructor: `public _MakoLexer() { this((java.io.Reader)null); }`
- Brace depth counter: `private int braceDepth = 0;` with `private void resetBraceDepth() { braceDepth = 0; }`

**States:**
```
%state EXPRESSION
%state TAG_ATTRS
%state CODE_BLOCK
%state MODULE_BLOCK
%state DOC_COMMENT
```

**Macros:**
- `LineTerminator = \r|\n|\r\n`
- `WhiteSpace = [ \t]+`

**YYINITIAL rules** (order matters — JFlex uses longest match, then first listed):
1. `"${"`  -> `yybegin(EXPRESSION); resetBraceDepth(); return EXPR_START;`
2. `"##" [^\r\n]*` -> `return LINE_COMMENT;` (single-line comment, entire match)
3. `"<%doc>"` -> `yybegin(DOC_COMMENT); return DOC_OPEN;`
4. `"<%!"` -> `yybegin(MODULE_BLOCK); return MODULE_OPEN;` (module-level code)
5. `"<%" [a-zA-Z]` -> Push back the letter with `yypushback(1)`, `yybegin(TAG_ATTRS); return TAG_OPEN;` (named tags like <%def, <%block, <%inherit, <%include, <%namespace, <%page)
6. `"<%" {WhiteSpace}` -> Push back whitespace, `yybegin(CODE_BLOCK); return CODE_OPEN;` (anonymous code block)
7. `"<%" {LineTerminator}` -> Push back line terminator, `yybegin(CODE_BLOCK); return CODE_OPEN;` (anonymous code block at end of line)
8. `"</" "%" [a-zA-Z]+ ">"` -> `return END_TAG;` (closing tags like </%def>, </%block>)
9. `^[ \t]* "%%" [^\r\n]*` -> `return TEMPLATE_TEXT;` (escaped percent — `%%` at line start is literal text; MUST come before control line rule)
10. `^[ \t]* "%" / [^%\r\n]` -> `return CONTROL_LINE;` (control line: % at line start followed by non-% character). **IMPORTANT:** This matches only the `%` prefix. The rest of the line content also needs to be consumed. Use a two-part approach: match `^[ \t]* "%" [^\r\n]*` as a single CONTROL_LINE token (entire line including leading whitespace, the %, and the keyword+body). The `/ [^%\r\n]` lookahead prevents matching `%%`. Combine: `^[ \t]* "%" [^%\r\n] [^\r\n]*` -> `return CONTROL_LINE;`
11. `{LineTerminator}` -> `return TokenType.WHITE_SPACE;` (newlines are whitespace)
12. `[^$<%\r\n#]+ | [$<%#]` -> `return TEMPLATE_TEXT;` (template text: consume runs of non-special characters, or individual special characters that weren't matched by earlier rules)
13. `[^]` -> `return TEMPLATE_TEXT;` (fallback for any remaining character)

**EXPRESSION state rules** (for `${...}` — PARS-02 brace depth tracking):
1. `"{"` -> `braceDepth++; return EXPR_CONTENT;`
2. `"}"` -> `if (braceDepth > 0) { braceDepth--; return EXPR_CONTENT; } else { resetBraceDepth(); yybegin(YYINITIAL); return EXPR_END; }`
3. `"|" / [^|]` -> `return FILTER_SEP;` (filter separator — only at top-level brace depth. Per research, `|` in EXPRESSION state is always filter separator when not `||`)
4. `"||"` -> `return EXPR_CONTENT;` (Python boolean OR stays as expression content)
5. `"|"` at end of input -> `return FILTER_SEP;` (edge case: `|` at end)
6. String literals: `\" ( [^\"\\] | \\. )* \"` -> `return EXPR_CONTENT;` and `' ( [^'\\] | \\. )* '` -> `return EXPR_CONTENT;` (skip string contents to avoid brace/pipe false matches inside strings)
7. `[^\}\{|\"']+` -> `return EXPR_CONTENT;` (runs of non-special chars)
8. `.` -> `return EXPR_CONTENT;` (fallback)

**TAG_ATTRS state rules** (for `<%tag attrs...%>`):
1. `"%>"` -> `yybegin(YYINITIAL); return TAG_CLOSE;`
2. `"/>"` -> `yybegin(YYINITIAL); return TAG_CLOSE;` (self-closing variant)
3. `[a-zA-Z_][a-zA-Z0-9_]*` -> `return TAG_ATTR_NAME;` (also catches the tag name itself — fine, it gets TAG_ATTR_NAME type which Phase 3 can refine)
4. `"="` -> `return TAG_ATTR_EQ;`
5. `\" [^\"]* \"` -> `return TAG_ATTR_VALUE;`
6. `' [^']* '` -> `return TAG_ATTR_VALUE;`
7. `{WhiteSpace} | {LineTerminator}` -> `return TokenType.WHITE_SPACE;`
8. `.` -> `return TokenType.BAD_CHARACTER;` (unexpected char in tag)

**CODE_BLOCK state rules** (for `<% code %>`):
1. `"%>"` -> `yybegin(YYINITIAL); return CODE_CLOSE;`
2. `[^%]+ | "%" / [^>]` -> `return CODE_CONTENT;` (everything until `%>`)
3. `"%"` -> `return CODE_CONTENT;` (lone % at end of input)

**MODULE_BLOCK state rules** (for `<%! code %>`):
1. `"%>"` -> `yybegin(YYINITIAL); return CODE_CLOSE;` (reuse CODE_CLOSE token)
2. `[^%]+ | "%" / [^>]` -> `return MODULE_CONTENT;`
3. `"%"` -> `return MODULE_CONTENT;`

**DOC_COMMENT state rules** (for `<%doc> ... </%doc>`):
1. `"</%doc>"` -> `yybegin(YYINITIAL); return DOC_CLOSE;`
2. `[^<]+ | "<" / [^/]` -> `return DOC_CONTENT;` (everything until `</%doc>`)
3. `"</" / [^%]` -> `return DOC_CONTENT;` (partial close that isn't `</%`)
4. `"<"` -> `return DOC_CONTENT;` (lone < at end)
5. `[^]` -> `return DOC_CONTENT;` (fallback)
