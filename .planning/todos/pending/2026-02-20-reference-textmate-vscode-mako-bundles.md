# Reference TextMate/VS Code Mako Bundles for Syntax Decisions

## Why

During Phase 4 gap closure, we investigated how other editors handle Mako expression highlighting. TextMate/VS Code bundles provide useful reference material for scope naming, color choices, and syntax granularity decisions in future phases.

## Sources

- **marconi/mako-tmbundle** - TextMate bundle for Mako templates
- **tommorris/vsc-mako** - VS Code extension for Mako templates

## Relevant For

- Phase 5+: color scheme refinements, scope naming conventions
- Any future work on expression/tag granularity in the syntax highlighter
- Alignment with community conventions for Mako syntax scopes
