### Integration Gap (Non-blocking)

**ANNOT-01 partial: `TagAttrCompletionProvider` missing explicit language guard**

`TagAttrCompletionProvider` in `MakoCompletionContributor.kt` registers under a `WHITE_SPACE` PSI pattern (language-neutral) without an explicit `file.language != MakoLanguage` guard. In non-Mako files, the provider fires on whitespace, walks the PSI tree silently, and returns no results. No functional break — classified as tech debt.
