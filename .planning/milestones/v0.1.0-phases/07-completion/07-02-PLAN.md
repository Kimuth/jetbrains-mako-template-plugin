   - Input: `myFixture.configureByText("test.mako", "<%<caret>")`

   - Input: `myFixture.configureByText("test.mako", "<%d<caret>")`
   - Call: `myFixture.completeBasic()`
   - Assert: result contains `"<%def"` (at minimum); result does not auto-complete away the popup for a single match (or if it does, use `myFixture.getLookupElementStrings()` pattern)

3. `testDefAttrCompletion` — caret on whitespace inside `<%def`:
   - Input: `myFixture.configureByText("test.mako", "<%def <caret>>")`
   - Call: `myFixture.completeBasic()`
   - Assert: result is not null; strings contain `"name"`, `"buffered"`, `"cached"`, `"filter"`, `"decorator"`

4. `testInheritAttrCompletion` — caret inside `<%inherit`:
   - Input: `myFixture.configureByText("test.mako", "<%inherit <caret>>")`
   - Call: `myFixture.completeBasic()`
   - Assert: strings contain `"file"`; strings do NOT contain `"name"` (which is a <%def attribute, not <%inherit)

5. `testNoCompletionInPlainHtml` — caret inside plain HTML with no `<%` preceding:

   - Call: `myFixture.completeBasic()`
   - Assert: `items?.map { it.lookupString } ?: emptyList()` does NOT contain any of `"<%def"`, `"<%block"`, `"<%inherit"`, `"<%include"`, `"<%namespace"`, `"<%page"`, `"<%doc"`
