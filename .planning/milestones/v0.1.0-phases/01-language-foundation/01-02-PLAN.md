<task type="auto">
  <name>Task 2: Register fileType in plugin.xml and verify build</name>
  <files>
    src/main/resources/META-INF/plugin.xml

  <action>
    Update `src/main/resources/META-INF/plugin.xml` to add the fileType extension point registration inside the existing empty `<extensions>` block (created by Plan 01).

    Add this inside the `<extensions defaultExtensionNs="com.intellij">` block:
    ```xml
    <fileType
        name="Mako Template"
        implementationClass="com.github.kimuth.jetbrainsmakotemplateplugin.MakoFileType"
        fieldName="INSTANCE"
        language="Mako Template"
        extensions="mako;mak"
        patterns="*.html.mako"/>
    ```

    The complete plugin.xml should look like:
    ```xml
    <idea-plugin>
        <id>com.github.kimuth.jetbrainsmakotemplateplugin</id>
        <name>Mako Template Support</name>
        <vendor>kimuth</vendor>

        <depends>com.intellij.modules.platform</depends>
        <depends>com.intellij.modules.python</depends>

        <extensions defaultExtensionNs="com.intellij">
            <fileType
                name="Mako Template"
                implementationClass="com.github.kimuth.jetbrainsmakotemplateplugin.MakoFileType"
                fieldName="INSTANCE"
                language="Mako Template"
                extensions="mako;mak"
                patterns="*.html.mako"/>
        </extensions>
    </idea-plugin>
    ```

    **String consistency checklist (MUST verify before saving):**
    - `name="Mako Template"` matches `MakoFileType.getName()` return value
    - `language="Mako Template"` matches the string in `Language("Mako Template")` constructor
    - `implementationClass` is the fully qualified class name of `MakoFileType`
    - `fieldName="INSTANCE"` works because `MakoFileType` is a Kotlin `object` (exposes synthetic `INSTANCE` field)
    - `extensions="mako;mak"` covers `.mako` and `.mak` (per user decision)
    - `patterns="*.html.mako"` covers the `.html.mako` compound extension (per user decision; uses `patterns` not `extensions` because compound extensions need glob matching)
