<objective>
Fix `getName()` and `setName()` in `MakoDefTagMixin` and `MakoBlockTagMixin` so named PSI elements expose correct names and explicitly reject unsupported mutations.

Purpose: The current `getName()` uses `findChildByType(TAG_ATTR_VALUE)` which returns the first attribute value regardless of which attribute it belongs to. For `<%def name="foo" args="()">` this returns "foo" by luck, but for `<%def args="()" name="foo">` it would return "()" — wrong. The fix pairs name lookup to the `name=` attribute key specifically. The current `setName()` silently returns `this`, giving callers the false impression that rename succeeded.

Output: Two corrected mixin files, one new test class covering both PSI-01 and PSI-02 contracts.
</objective>

    GREEN phase: Fix MakoDefTagMixin.getName() and MakoBlockTagMixin.getName().

    The grammar `tag_attribute ::= TAG_ATTR_NAME TAG_ATTR_EQ TAG_ATTR_VALUE` is a PRIVATE rule, meaning GrammarKit does NOT create a composite PSI node for it. Instead, TAG_ATTR_NAME, TAG_ATTR_EQ, and TAG_ATTR_VALUE appear as flat sibling tokens directly under the def_tag/block_tag ASTNode.

    Fix algorithm: Walk `node.getChildren(null)` (all child ASTNodes). When a child has elementType == TAG_ATTR_NAME and text == "name", the very next child with elementType == TAG_ATTR_VALUE is the name value. Use `treeNext` traversal or collect children into a list and find the pair:

    ```kotlin
    override fun getName(): String? {
        var child = node.firstChildNode
        while (child != null) {
            if (child.elementType == MakoTokenTypes.TAG_ATTR_NAME && child.text == "name") {
                // Walk forward to find the corresponding TAG_ATTR_VALUE
                var sibling = child.treeNext
                while (sibling != null) {
                    if (sibling.elementType == MakoTokenTypes.TAG_ATTR_VALUE) {
                        return sibling.text.trim('"', '\'')
                    }
                    // Stop if we hit another TAG_ATTR_NAME (next attribute started, no value found)
                    if (sibling.elementType == MakoTokenTypes.TAG_ATTR_NAME) break
                    sibling = sibling.treeNext
                }
                return null
            }
            child = child.treeNext
        }
        return null
    }
    ```
