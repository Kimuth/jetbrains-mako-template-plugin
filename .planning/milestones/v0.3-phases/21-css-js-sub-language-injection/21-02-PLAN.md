IMPORTANT: CSS/JS completions ONLY fire when the respective language plugins are installed. PyCharm Community does not bundle CSS or JavaScript plugins. If you are running PyCharm Community without these plugins, the injectors silently no-op — this is EXPECTED behavior per research findings.

To fully verify HINJ-05/HINJ-06, you need one of:
- PyCharm Professional (bundles CSS + JavaScript)
- IntelliJ IDEA Ultimate (bundles CSS + JavaScript)

  <what-built>
MakoCssInjector (Phase 21-01) is registered as a multiHostInjector and loaded in the running IDE. It injects CSSLanguage into XmlText nodes inside HTML PSI tree `<style>` elements in `.mako` files. JavaScript injection into `<script>` elements is handled by the platform's HtmlScriptLanguageInjector (already registered in PyCharmCorePlugin.xml).
  </what-built>
  <how-to-verify>
With `hinj05_hinj06_test.mako` open in the running IDE, check each item:

**HINJ-05 (CSS in &lt;style&gt;):**
1. Place cursor inside the `<style>` block, after `color: ` — press Ctrl+Space
   - Expected (CSS plugin installed): CSS value completions appear (red, blue, color names)
   - Expected (CSS plugin NOT installed): No completions or plain-text word completion only

2. Place cursor after `background-` inside the style block — press Ctrl+Space
   - Expected (CSS plugin installed): `background-color`, `background-image`, etc.

3. Type `invalidcss: !@#` inside the `<style>` block
   - Expected (CSS plugin installed): Red error squiggle on the invalid CSS

**HINJ-06 (JavaScript in &lt;script&gt;):**
4. Place cursor after `document.` inside the `<script>` block — press Ctrl+Space
   - Expected (JavaScript plugin installed): Member completions appear (getElementById, querySelector, body, etc.)
   - Expected (JavaScript plugin NOT installed): No JavaScript completions

5. Observe whether any JavaScript errors appear inside the `<script>` block

**Regression check:**
6. Verify `${greeting}` has no red HTML error squiggle (CRCT-01 not broken)
7. Verify Python injection active: `${greeting}` shows Python "Unresolved reference 'greeting'" (correct — Python validation via injection)
8. Open a separate Mako file with `<%def>` blocks; verify structure view still shows def nodes

**Double-injection check (if CSS plugin is present):**
9. Press Ctrl+Space inside `<style>` block; confirm completions appear exactly once (no duplicates that would indicate double-injection)
  </how-to-verify>
