  <how-to-verify>
In the running IDE (launched by Task 1), open or create a .mako file containing the test content from Task 1. Then verify each criterion:

**CRCT-01 — ${cls} false positive (REQUIRED):**
1. Place cursor on `<div class="${cls}">Hello world</div>`
2. Confirm: NO red error squiggle appears on `${cls}` or the surrounding quotes
3. Expected: The expression boundary is opaque to the HTML parser; MakoErrorFilter suppresses any boundary errors

**CRCT-02 — Control line false positives (REQUIRED):**
1. Look at the `%for item in items:` and `%endfor` lines
2. Confirm: NO red HTML error squiggles on these control lines
3. Expected: CONTROL_LINE tokens are OuterLanguageElement boundaries; MakoErrorFilter suppresses errors

**HINJ-01 — HTML syntax coloring:**
1. Look at the `<div class="container">`, `<h1>`, `<p>` tags in the TEMPLATE_TEXT region
2. Confirm: HTML tags are visually colored (different color from plain Mako text)
3. If NO coloring: note as gap — MakoEditorHighlighter may not be activating; check IDE event log for errors

**HINJ-04 — HTML error squiggles (HTML5 spec behavior):**
1. Look at `<span>unclosed span` — confirm a red/yellow squiggle appears (correct — span is not optional-close)
2. Look at `<p>unclosed paragraph` — confirm NO squiggle appears (correct HTML5 — p is optional-close)
3. This partial behavior is expected and spec-correct; do NOT attempt to make `<p>` show a squiggle

**HINJ-05 — CSS in `<style>`:**
1. Place cursor inside the `<style>` block, type `color:` and press Ctrl+Space
2. Confirm: CSS property value completions appear (e.g., color names, hex values) OR only HTML completions appear
3. Record result as WORKING or GAP

**HINJ-06 — JS in `<script>`:**
1. Place cursor inside the `<script>` block, type `document.` and press Ctrl+Space
2. Confirm: JavaScript member completions appear (e.g., getElementById, querySelector) OR only HTML completions appear
3. Record result as WORKING or GAP

Report results in this format:
- CRCT-01: PASS or FAIL
- CRCT-02: PASS or FAIL
- HINJ-01: PASS or GAP (describe what you see)
- HINJ-04: PASS (span squiggle yes, p squiggle no) or describe deviation
- HINJ-05: PASS (CSS completions) or GAP (describe)
- HINJ-06: PASS (JS completions) or GAP (describe)
